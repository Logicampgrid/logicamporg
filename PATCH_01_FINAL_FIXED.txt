🆘 DEPANNAGE:

PROBLEME: Logo ne s'affiche pas
   Solution:
   1. Ouvrir URL directe: https://logicamp.org/img/logotsp1.gif
   2. Si 404: uploader le fichier logotsp1.gif dans /img/
   3. Verifier permissions: chmod 644 logotsp1.gif
   4. Vider cache navigateur: Ctrl+Shift+R

PROBLEME: Images boutiques ne s'affichent pas
   Solution:
   1. Ouvrir URLs directes:
      - https://logicamp.org/shopimg/logivantiq.jpg
      - https://logicamp.org/shopimg/gizmo2.jpg
   2. Si 404: creer dossier /shopimg/ et uploader les images
   3. Verifier permissions: chmod 644 *.jpg
   4. Les placeholders s'afficheront en attendant

PROBLEME: Spinner continue de tourner
   Solution:
   1. Ouvrir Console (F12)
   2. Onglet Console: chercher erreurs JavaScript
   3. Onglet Network: chercher requetes qui echouent
   4. Verifier que les 7 images slideshow existent (img0-img6.png)
   5. Vider tous les caches:
      - Navigateur: Ctrl+Shift+R
      - Serveur: Redemarrer Apache
      - PHP: Redemarrer service PHP

PROBLEME: Page affiche caracteres bizarres
   Solution:
   1. Verifier encodage fichier: UTF-8 sans BOM
   2. Utiliser editeur Notepad++ ou VS Code
   3. Sauvegarder en UTF-8 sans BOM
   4. Re-uploader le fichier
