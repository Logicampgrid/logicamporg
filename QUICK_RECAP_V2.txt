PROBLÈME : Caractères �
→ Vérifiez encodage : file -i index-logicamp-v2.php
→ Doit être UTF-8
→ Header ligne 13 : charset=UTF-8

PROBLÈME : Images ne chargent pas
→ Vérifiez chemin : /wamp/www/img/slideshow/

→ Videz cache : Ctrl + Shift + R
→ Vérifiez chemin : style-logicamp-v2.css

→ Remplacez lignes 34-37 par vos fonctions DB

→ Vérifiez formcheck.php existe
→ Testez captcha en console (F12)
