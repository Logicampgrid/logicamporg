## 📱 Responsive Breakpoints

### Desktop (>992px)
- Navigation horizontale complète
- Hero en 2 colonnes (texte + formulaire côte à côte)
- Footer en 3 colonnes
- Vidéos en largeur optimale

### Tablet (768px - 991px)
- Navigation avec menu burger
- Hero en 2 colonnes (ajusté)
- Formulaire légèrement plus large
- Footer en 3 colonnes (ajusté)

### Mobile (<767px)
- Menu burger
- Hero en 1 colonne (texte au-dessus, formulaire en-dessous)
- Cards en pleine largeur
- Footer empilé (1 colonne)
- Avatars plus petits
- Textes réduits

## ✨ Effets spéciaux

### Glassmorphism
```css
background: rgba(15, 23, 42, 0.8);
backdrop-filter: blur(20px);
border: 1px solid rgba(0, 212, 255, 0.2);
```
Utilisé sur : formulaire, cards, navigation

### Gradient Text
```css
background: linear-gradient(135deg, #00d4ff 0%, #7b2cbf 100%);
-webkit-background-clip: text;
-webkit-text-fill-color: transparent;
```
Utilisé sur : titres importants, logo

### Glow Animation
```css
box-shadow: 0 10px 40px rgba(0, 212, 255, 0.1);
```
Avec animation au hover :
```css
box-shadow: 0 15px 50px rgba(0, 212, 255, 0.3);
```

### Smooth Scroll
Navigation avec défilement fluide vers les sections

## 🔧 Personnalisation facile

### Changer les couleurs
Modifiez uniquement les variables CSS (lignes 8-18 de style-modern.css) :
```css
:root {
    --primary-color: #VotreCouleur;
    --secondary-color: #VotreCouleur;
    --accent-color: #VotreCouleur;
}
```
Tout le site s'adaptera automatiquement !

### Changer le logo
Modifiez le texte dans index-modern.php (lignes 57-61) :
```html
<span class=\"brand-text\">VOTRE<span class=\"brand-highlight\">LOGO</span></span>
```

### Ajuster l'espacement
Modifiez les classes Bootstrap :
- `py-5` : padding vertical
- `mb-4` : margin bottom
- `gap-4` : espacement dans flex/grid
